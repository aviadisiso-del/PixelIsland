# Pixel Island

A Dynamic Island for the Pixel 7. The black pill sits exactly on the camera hole and springs out of it.

## Build and install
1. Install Android Studio and open this folder (`PixelIsland`). Let Gradle sync.
2. On the phone: Settings > About phone > tap Build number 7 times, then enable USB debugging.
3. Connect the phone and press Run, or Build > Build APK(s) and install the APK.

## First run (inside the app)
1. Allow display over other apps.
2. Allow notification access (needed for music and notification previews).
3. Allow notifications (Android 13+).
4. Press Start island, then Test animation.
5. Use the three sliders so the pill lines up exactly with the camera hole when idle.

## What it does now
- Music: compact pill with album art and moving bars. Long-press to expand (art, title, seek bar, previous / play / next). Tap to open the player app.
- Notification previews: the pill expands for a few seconds. Tap to open the notification.
- Charging: lightning bolt and battery percentage when you plug in.
- Swipe up or tap outside to collapse.
